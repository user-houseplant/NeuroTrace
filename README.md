# NeuroTrace
NeuroTrace — Tracing genetic risk across the brain

## Spatial Genomic Analysis of Selective Vulnerability in Neurodegenerative Diseases

This project investigates whether disease-associated genes show
region-specific expression patterns in the human brain and whether
these patterns correspond to regions affected by neurodegenerative
diseases.

## Current Focus

- Allen Human Brain Atlas
- GWAS-derived disease-associated genes
- Regional gene expression
- Permutation testing
- Multiple-testing correction
- Spatial null models
